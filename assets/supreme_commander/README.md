# Supreme Commander animation frames

Supreme Commander uses the standard per-frame animation naming convention but is intended for **512 × 512 px transparent PNG frames** instead of the normal 256 × 256 unit art.

Expected files:

- `idle_1.png`
- `running_1.png`
- `running_2.png`
- `idle_shooting_1.png`
- `idle_shooting_2.png`
- `shooting_1.png`
- `shooting_2.png`
- `dead_1.png`

The sprite is rendered larger than a normal Captain, but gameplay collision/hit detection deliberately keeps the normal Captain/soldier hitbox.
