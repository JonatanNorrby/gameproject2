# Class projectile images

Expected class-specific projectile files:

- `rifleman.png`
- `rocketeer.png`

These override the generic projectile images for shots fired by that class. Captains currently use the image of their underlying class. Each file is one static transparent PNG; no animation frames are used.

Shockblade is intentionally omitted because it is a melee class and does not create projectile entities.
