# Class projectile images

Expected class-specific projectile files:

- `rifleman.png`
- `rocketeer.png`
- `anti_air.png`

These override the generic projectile image for shots fired by that class. Captains use the image of their underlying class. Each file is one static transparent PNG; no animation frames are used.

`anti_air.png` represents the guided interceptor and should point right/east in source art. Shockblade is omitted because it is melee. Drone Pilot is omitted because its battlefield drone drops a procedural stun grenade rather than firing a projectile entity.
