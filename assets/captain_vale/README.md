# Captain Vale animation frames

Captain Vale has independent art and does not inherit Rifleman images.

Required files:

- `idle_1.png`
- `running_1.png`
- `running_2.png`
- `idle_shooting_1.png`
- `idle_shooting_2.png`
- `shooting_1.png`
- `shooting_2.png`
- `dead_1.png`

`idle_1.png` is also used as Captain Vale's portrait on the Captain selection screen.

See `assets/ANIMATION_FRAMEWORK.md` for alignment, facing, sizing, and fallback rules.
