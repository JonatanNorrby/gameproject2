# Rocketeer animation frames

Upload the Rocketeer PNG frames directly into this folder.

Required files:

- `idle_1.png`
- `running_1.png`
- `running_2.png`
- `idle_shooting_1.png`
- `idle_shooting_2.png`
- `shooting_1.png`
- `shooting_2.png`
- `dead_1.png`

`idle_1.png` is also used as the Rocketeer portrait on reinforcement upgrade cards.

See `assets/ANIMATION_FRAMEWORK.md` for alignment, facing, sizing, and fallback rules.
