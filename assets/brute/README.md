# Brute assets

Place Brute animation frames in this folder using the standard character names from `assets/ANIMATION_FRAMEWORK.md`:

- `idle_1.png`
- `running_1.png`, `running_2.png`
- `idle_shooting_1.png`, `idle_shooting_2.png`
- `shooting_1.png`, `shooting_2.png`
- `dead_1.png`

Use transparent PNGs. Missing frames fall back safely at runtime.
